# trip-planner 🧳

> 预算驱动的旅行规划 Skill：**先需求、后目的地；先总预算、后酒店；先核验、再下单** —— 外加一套浏览器自动盯价的实战配方。

**为什么存在**：行程规划容易退化成景点堆砌；酒店信息官网与住客评论各说各话、名称误判会污染整套方案；刷机票酒店价格费时还总错过低点。本 skill 把十步决策流程与三平台盯价配方固化成可复用模板，换目的地只需替换日期、预算与偏好。

## 特色

- ✅ **十步流程**：需求 → 预算筛目的地 → 安全度排查 → 结构分预算 → 酒店四维核验 → 海滩体验筛选 → 身份硬核验 → 每日行程 → 预算校准 → 可信度分级 → 交付清单
- 🎯 **目的驱动**：你只说想要什么体验、喜欢什么感觉——目的地与剩余全部由方案推导，不要求先选国家
- 🛡️ **安全度两层排查**：规划期 CDC 疾病/备孕健康门槛（可一票否决目的地）＋ 订票时与出发前 15 天的政治地貌复核（出发国-目的地-中转国）
- **酒店身份硬规则**：集团 ≠ 品牌；标记「已订」前四要素（完整名称 + 入住日期 + 实际价格 + 预订状态）缺一不可；发现误判立即撤回全部关联结论
- **信息可信度五级**：已确认 / 官方公布 / 住客反馈 / 合理估算 / 待核实 —— 每个结论都可溯源
- **价格监控配方**：携程、Booking、Agoda 三平台浏览器实抓 + 静默契约 cron（平时零打扰，新低 / 破阈值 / 出错才播报）
- **发布脱敏铁律**：案例数值全占位符；真实行程参数只存本地 agent memory 与 cron 配置

## 安装

**Hermes Agent（本 skill 的原生环境）**

```bash
git clone https://github.com/SPA3K/trip-planner.git
mkdir -p ~/.hermes/skills/travel
cp -r trip-planner ~/.hermes/skills/travel/trip-planner
```

**Claude Code 及其他支持 Agent Skills 的环境**

```bash
git clone https://github.com/SPA3K/trip-planner.git
mkdir -p ~/.claude/skills
cp -r trip-planner ~/.claude/skills/trip-planner
```

安装后对 agent 说「用 trip-planner 规划一次旅行」即可触发。

## 快速开始

1. **需求对话**：agent 自然对话收集出发地 / 日期 / 预算 / 偏好 / 黑名单 —— 不甩长问卷，已确认信息不重复问
2. **目的地横评**：2-3 个方案 + 六维评分（体验 / 预算 / 交通 / 天气 / 酒店性价比 / 舒适度），每个方案给理由
3. **酒店核验**：四维并行（官网信息 × 真实评论 × 地图位置 × 同条件比价）+ 身份硬规则
4. **盯价上线**：改配置常量 → `--verbose` 实测两轮 → 挂 `no_agent` cron，静默等播报
